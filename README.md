# NCMMSC 2026 会议论文导读 / Paper Guide

> 🌐 **在线访问 / Live site：<https://logic-bean.github.io/nvmmsc-2026-paperguide/>**

NCMMSC 2026（第二十一届全国人机语音通讯学术会议）论文导读页，**中英双语**，沿用 Interspeech 2026 论文信息整理框架。

## 内容

- **365 篇论文**，按 13 个大会主题分类（结合官方技术程序分会场）
- 每篇论文 **7 维导读**：一句话总结 / 研究动机 / 拟解决问题 / 主要方法 / 使用数据集 / 实验结果 / 主要贡献
- **统计分析**：
  - 作者索引（1123 位，A–Z 分组 + 高产作者 Top 12）
  - 数据集索引（21 个被引数据集，含发布时间 / 发布人 / 特点 / 规模 / 质量 / 影响力）
  - 数据治理汇总（5 类数据工程活动：定义与范围 + 主要成果≤3 点 + 相关论文）
- 右上角 **「EN / 中文」一键切换**

## 使用

- 直接打开 `index.html`（即 v11 版本，单文件、离线可用）
- 论文 PDF 链接为相对路径 `NCMMSC2026-论文集/papers/...`。**本仓库未包含论文集 PDF**（体积过大），因此线上点击 PDF 链接会 404。若需本地使用 PDF，请将 `NCMMSC2026-论文集/` 目录与 `index.html` 放在同一级目录。

## 说明

- 论文数据来自官方《技术程序》详细议程与本地论文集 PDF。
- 中文 7 维导读由 DeepSeek 翻译/提炼；英文模式回落到原始英文摘要的规则化抽取。
- 页面除 PDF 外无任何外部依赖。
